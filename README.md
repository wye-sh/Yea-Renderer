# Renderer

The 3D rendering engine for Yea games: physically based materials, a sun and any number of
coloured point and spot lights, light culling on the GPU, soft cascaded sun shadows and cached
shadows for local lights, ambient occlusion, contact shadows, reflection probes, temporal
antialiasing, automatic exposure and tonemapping. Open its example view, Renderer,
to see everything it does and tune it in F1.

MIT licensed. Our own code throughout; nothing of anyone else's ships with it.
